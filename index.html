Questions

A few quick answers.

Which theme is the default?

Snowy is the default theme. Switch to Midnight or Sunset from Settings.

Does this page have real account authentication?

No. The included login/sign-up is a front-end demo stored in this browser only. It is not secure authentication and does not sync between devices.

Can users reset a forgotten password?

A production system needs a server-side account database and secure password-reset flow.

What does version 1.3.6 mean?

The website displays 1.3.6 as requested. Verify that the linked app download is actually that release.
